# 機能一覧

[要件定義書](../要件定義書.md)で定義した方針に基づく、本システムの機能要件一覧。

## 機能要件

| No | 機能名 | 概要 |
|---|---|---|
| F-01 | カテゴリ一覧表示 | 登録済みのカテゴリ(食費・交通費・給与など)を一覧表示する |
| F-02 | カテゴリ登録 | 新しいカテゴリを、名称・種別(収入用/支出用)を指定して登録する |
| F-03 | カテゴリ編集 | 既存カテゴリの名称を編集する |
| F-04 | カテゴリ削除 | 既存カテゴリを削除する(削除済みカテゴリを参照する取引がある場合の扱いは実装時に定める) |
| F-05 | 取引登録 | 収入・支出を1件、日付・金額・種別(収入/支出)・カテゴリ・メモを指定して登録する |
| F-06 | 取引編集 | 登録済みの取引の内容を編集する |
| F-07 | 取引削除 | 登録済みの取引を削除する |
| F-08 | 取引一覧表示 | 登録済みの取引を、日付の新しい順に一覧表示する |
| F-09 | 日付によるフィルタリング | 取引一覧を、指定した期間(開始日・終了日)で絞り込む |
| F-10 | カテゴリによるフィルタリング | 取引一覧を、指定したカテゴリで絞り込む |
| F-11 | 月別集計 | 指定した月の収入合計・支出合計・差引(収支)を集計して表示する |
| F-12 | カテゴリ別集計 | 指定した期間における、カテゴリごとの合計金額を集計して表示する |

F-09・F-10のフィルタリングとF-11・F-12の集計は組み合わせて使用できる(例: 「今月」かつ
「食費」で絞り込んだ合計を見る、など)ことを基本方針とする。

## スコープ外項目

以下は本バージョンでは対象外とする(詳細は[要件定義書](../要件定義書.md)の
「今後の拡張案」を参照)。

| No | 機能名 | 対象外とする理由 |
|---|---|---|
| Z-01 | 会員登録・ログイン | シングルユーザー前提のため、認証機能は持たない |
| Z-02 | グラフ表示(円グラフ・棒グラフ) | 集計結果はテーブル・数値表示のみとし、グラフ描画は発展課題とする |
| Z-03 | 予算設定・予算対比 | カテゴリごとの月間予算機能は発展課題とする |
| Z-04 | CSVエクスポート・インポート | データ入出力機能は発展課題とする |
