# 技術スタック

家計簿アプリ「カケイボ」の開発環境・使用技術。

## 全体構成

フロントエンド(Next.js)とバックエンド(Ruby on Rails, APIモード)を分離した構成とし、
データはMySQLに永続化する。フロントエンドはバックエンドが提供するREST APIを介して
データの取得・更新を行う。

```
[ブラウザ] ⇄ Next.js(フロントエンド) ⇄ REST API(JSON) ⇄ Ruby on Rails(バックエンド) ⇄ MySQL
```

## フロントエンド

| 分類 | 内容 | バージョン |
|---|---|---|
| 言語 | TypeScript | - |
| フレームワーク | Next.js(React) | 16.2.12 |
| 実行環境 | Node.js / npm | v24.18.0 / 11.16.0 |
| API通信 | fetch APIによるバックエンドREST APIの呼び出し(`next.config.ts`の`rewrites()`で`/api`をバックエンドへ中継) | - |

## バックエンド

| 分類 | 内容 | バージョン |
|---|---|---|
| 言語 | Ruby | 3.3.12(rbenv導入) |
| フレームワーク | Ruby on Rails(APIモード。ビュー・アセットパイプラインは使用しない) | 8.1.3 |
| ビルドツール | Bundler | 4.0.17 |
| API方式 | REST(JSON) | - |
| データアクセス | Active Record(DBアダプタは`trilogy`) | - |

## データベース

| 分類 | 内容 | バージョン |
|---|---|---|
| DBMS | MySQL(ローカルはDockerコンテナ、本番はAWS RDS) | 8 |

上記バージョンは実際の実装環境([ローカル開発環境セットアップ](ローカル開発環境セットアップ.md)参照)で
確定したものであり、今後のライブラリ更新に応じて随時見直す。

## 前回(タスクボードアプリ)からの変更点

学習のため、前回の技術スタックから意図的にすべて変更している。

| 分類 | 前回 | 今回 |
|---|---|---|
| フロントエンド | React(Vite, JavaScript) | Next.js(TypeScript) |
| バックエンド | Spring Boot(Java) | Ruby on Rails(Ruby) |
| データベース | PostgreSQL | MySQL |
