# 画面設計書

[機能一覧](機能一覧.md)を実現するための画面構成。

## 画面一覧

| No | 画面名 | 概要 |
|---|---|---|
| S-01 | ダッシュボード(月別集計) | 起動時のトップ画面。月を選択し、その月の収入合計・支出合計・差引・カテゴリ別内訳を表示する |
| S-02 | 取引一覧 | 登録済みの取引を一覧表示し、期間・カテゴリで絞り込める。取引の編集・削除もここから行う |
| S-03 | 取引登録・編集フォーム | 取引一覧上でモーダルとして開き、日付・金額・種別・カテゴリ・メモを入力する |
| S-04 | カテゴリ管理 | カテゴリの一覧表示、および登録・編集・削除を行う |

## 画面構成要素

### S-01 ダッシュボード(月別集計)

- 月選択コントロール(前月/翌月への移動、または年月選択)
- 選択中の月の収入合計・支出合計・差引(サマリー表示)
- カテゴリ別の支出内訳(カテゴリ名と金額の一覧)
- 「取引一覧」「カテゴリ管理」への導線

### S-02 取引一覧

- 期間指定フィルタ(開始日・終了日)
- カテゴリ指定フィルタ(プルダウン等での単一〜複数選択)
- 取引テーブル(日付・種別・カテゴリ・金額・メモ・編集/削除ボタン)
- 「新規登録」ボタン(S-03をモーダルで開く)

### S-03 取引登録・編集フォーム

- 日付入力
- 種別選択(収入/支出)
- カテゴリ選択(種別に応じたカテゴリ一覧を表示)
- 金額入力
- メモ入力(任意)
- 保存・キャンセルボタン

### S-04 カテゴリ管理

- カテゴリ一覧(名称・種別)
- 新規登録フォーム(名称・種別)
- 各カテゴリの編集・削除ボタン

## 画面遷移

```
S-01 ダッシュボード ⇄ S-02 取引一覧 ⇄ (モーダル) S-03 取引登録・編集フォーム
        ⇅
S-04 カテゴリ管理
```

- 起動直後はS-01(ダッシュボード)を表示する
- S-02(取引一覧)からS-03(取引登録・編集フォーム)はモーダル表示とし、画面遷移は発生しない
- S-01・S-02・S-04はナビゲーション(ヘッダー等)から相互に行き来できる
