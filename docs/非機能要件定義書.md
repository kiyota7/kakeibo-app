# 非機能要件定義書

[要件定義書](../要件定義書.md)を満たすための非機能要件。

## 動作環境

| 項目 | 内容 |
|---|---|
| 対応ブラウザ | Google Chrome、Safari(いずれも最新版) |
| 画面サイズ | PCのブラウザ画面を主対象とする(スマートフォン最適化は対象外) |
| 利用者数 | シングルユーザー前提(同時複数アクセスは想定しない) |

## 性能

- 取引一覧・集計結果は、通常のデータ量(数百件程度)であれば体感で待たされることなく表示されること

## ユーザビリティ

- 主要な操作(取引の登録・絞り込み・集計確認)は、マニュアルなしで直感的に行えること
- 入力エラー(必須項目未入力、金額に数値以外を入力等)は、画面上でわかりやすく表示すること

## セキュリティ

- 本システムはシングルユーザー・個人利用を前提とし、ログイン機能・アクセス制御は持たない
- 本番環境では、データベースへのアクセスをアプリケーションサーバーからのみに制限する
  (詳細は[インフラ構成](インフラ構成.md)を参照。次フェーズで作成)

## 保守性

- フロントエンド・バックエンド・データベースを分離した3層構成とし、それぞれ独立して
  開発・修正できるようにする(詳細は[技術スタック](技術スタック.md)参照)
